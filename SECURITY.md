# Security

If you find a security problem in HANGAR01, such as a leaked key, a way to abuse the contact or report forms, or a cross-site scripting bug, please report it privately rather than in a public issue.

Report it through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Only the maintainers see the report.

Say what you found, where, and how to reproduce it. We'll credit you in the fix unless you'd rather stay anonymous.

The live site, [www.hangar01.space](https://www.hangar01.space), always runs the `main` branch, so only `main` is supported.
